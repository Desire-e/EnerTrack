# EnerTrack

B2B website for a fictitious energy management company that offers IoT-based energy monitoring solutions, targeting industrial and commercial clients.

**Live demo:** [https://ener-track-bay.vercel.app/](https://ener-track-bay.vercel.app/)

---

## Features
- Four pages: Home, Products, About, Contact
- Contact form with validation
- Tab system in Products, synchronized with the URL (`?tab=...`)
- Scroll animations, page transitions, and micro-interactions with Motion
- Fully responsive (mobile-first) design
- Floating AI chatbot widget, available throughout the website, with company context
- Basic SEO (metadata, Open Graph)

---

## Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Motion
- **Validation:** Zod
- **AI:** AI SDK + Groq (openai/gpt-oss-120b)
- **Markdown rendering:** react-markdown
- **Hosting:** Vercel
- **Version Control:** Git + GitHub

Exact versions in [`package.json`](./package.json).

## Getting Started

### Requirements

- Node.js 20+
- npm

### Steps

```bash
# Clone the repository
git clone https://github.com/Desire-e/EnerTrack.git
cd EnerTrack

# Install dependencies
npm install

# Configure environment variables (see next section)
cp .env.example .env.local

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

> **Note:** Always access via http://localhost:3000. If you open the URL generated by next dev (or any origin other than localhost), Next.js will block internal requests from the development server for security reasons, and some animations/hooks will stop working correctly.

## Environment variables

The chatbot requires a Groq API key:

```env
GROQ_API_KEY=your_api_key
```

1. Create an account on [console.groq.com](https://console.groq.com/)
2. Generate an API key from *API Keys*
3. Add it to `.env.local`

> **Important:** The variable should never be prefixed with `NEXT_PUBLIC_`, as it's a server-side secret and must not be exposed to the browser.

## Project structure

```text
src/app/
    _components/        # Global components
    _data/              # Global structured data
    _home/              # Home page 
        _components/
        _data/
    _types/             # Global TypeScript types
    _utils/             # Global logic files
    about/              # About page
        _components/
        _data/
        _types/
    api/
        chatbot/        # Chatbot route handler 
    contact/            # Contact page
        _components/    
        _utils/
    products/           # Products page
        _components/
        _data/
        _types/
    globals.css
    icon.svg            # Favicon
    layout.tsx
    page.tsx
    robots.ts
    sitemap.ts
    template.tsx         # Page transition animation
```
This project follows a structure strategy where the project files are split by feature or route: Shared app code in app/ folder, specific app code inside its own route segment (e.g: app/about/). 

Convention: Folders with underscores (e.g: `_components`) are not part of App Router routing. They are used to organize non-route files alongside routes.

## Technical decisions

- **Motion instead of vanilla CSS:** Motion is used for scroll animations, page transitions, gestures, and other interactive animations. Simpler hover effects and transitions are handled with Tailwind CSS
- **Page transitions with `template.tsx` instead of `layout.tsx`:** `template.tsx` is re-rendered on every navigation, which is necessary for `AnimatePresence` to detect an exit
- **Product Tabs with `useSearchParams`, instead of `useState`:** It prevents the URL and local state of the component from desynchronizing when navigating from external links (e.g., from the footer)
- **Groq instead of OpenAI**: Free, fast provider, no credit card required, and can be integrated via Vercel AI SDK (`@ai-sdk/groq`)

## AI Chatbot

The website includes a floating AI chatbot available across all pages.

- **Model:** `openai/gpt-oss-120b` via Groq
- **AI stack:** AI SDK, `@ai-sdk/groq`, and `@ai-sdk/react`
- **System prompt:** The system prompt is generated from the same structured data used by the website, avoiding duplicated company information
- **API route:** `/api/chatbot`
- Streaming responses and Markdown rendering
